## Enhanced constructs

Water is H~2~O and the 5^th^ element, with :sparkles: emoji shortcodes.

Edit anywhere above — the markdown syntax stays hidden and the file updates
silently underneath. Format with Ctrl+B / Ctrl+I / Ctrl+K (or the toolbar),
set headings with Ctrl+Shift+1–6 (Ctrl+Shift+0 clears). Press Ctrl+E for the
raw view — the cursor stays exactly where it was.

## Pagination

Everything below exists to give the page-accurate layout something to paginate.
Turn on the layout view and the document flows into real pages at the size and
margins from Page setup, with the status bar showing which page the cursor is on.

Scrolling stays in step with the live preview: the syntax markers for whichever
line holds the cursor reveal themselves as it arrives and hide again as it
leaves, so text never shifts under you while you read.
