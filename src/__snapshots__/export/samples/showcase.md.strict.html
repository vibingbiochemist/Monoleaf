Comments

The binding affinity was sub-nanomolar in the second assay. Open the Comments sidebar to see the thread attached to the highlighted phrase; a plain markdown viewer shows only the clean prose.

Tracked changes

Turn on Track changes (Ctrl+Shift+E) and edit below; it produces CriticMarkup like this: the dose was {10 mg~>20 mg} given {++once ++}daily, and the {--preliminary --}results held. You can also {==highlight==} passages and leave {>>a reviewer note<<} inline. Use the ✓ / ✗ toolbar buttons to accept or reject each change.
